# 📊 Sales Management System (WinForms)

This is a **.NET (WinForms)** desktop application developed to manage sales operations, track product inventory, and process customer orders. The application allows sales representatives to register products, process sales, and track revenue, all backed by an **MSSQL** database for secure data storage.

---

## 🚀 Features

- 🛍 **Product Management**: Add, update, and delete product records.
- 🧾 **Order Processing**: Process customer orders and keep track of sales.
- 📈 **Revenue Tracking**: Track total sales and product quantities sold.
- 💾 **Database Integration**: All data, including products, orders, and sales, is stored in an **MSSQL** database.
- 🖥 **WinForms User Interface**: A simple and user-friendly interface that makes it easy to manage sales operations.

---

## 🧱 Technologies

- **Language**: C#
- **Platform**: .NET (WinForms)
- **Database**: Microsoft SQL Server
- **ORM**: Entity Framework
- **IDE**: Visual Studio 2022
